
# Programming Tech Domains Guide

## 1. Web Development
- **HTML & CSS (2-4 weeks)**
  - Resources: [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/HTML), [FreeCodeCamp](https://www.freecodecamp.org/)
- **JavaScript (4-6 weeks)**
  - Resources: [JavaScript.info](https://javascript.info/), [Eloquent JavaScript (book)](https://eloquentjavascript.net/)
- **Front-End Frameworks:**
  - **React (4-6 weeks)**
    - Resources: [React Official Documentation](https://reactjs.org/docs/getting-started.html)
  - **Angular (4-6 weeks)**
    - Resources: [Angular Official Documentation](https://angular.io/docs)
  - **Vue.js (3-5 weeks)**
    - Resources: [Vue.js Official Documentation](https://vuejs.org/v2/guide/)
- **Back-End Development:**
  - **Node.js (4-6 weeks)**
    - Resources: [Node.js Documentation](https://nodejs.org/en/docs/)
  - **Django (4-6 weeks)**
    - Resources: [Django Official Documentation](https://docs.djangoproject.com/en/stable/)
  - **Ruby on Rails (4-6 weeks)**
    - Resources: [Ruby on Rails Guides](https://guides.rubyonrails.org/)
- **Databases:**
  - **SQL (MySQL/PostgreSQL) (3-5 weeks)**
    - Resources: [MySQL Documentation](https://dev.mysql.com/doc/), [PostgreSQL Documentation](https://www.postgresql.org/docs/)
  - **NoSQL (MongoDB) (3-5 weeks)**
    - Resources: [MongoDB Documentation](https://docs.mongodb.com/)
- **Advanced Topics:**
  - **Web Performance (2-4 weeks)**
    - Resources: [Google Web Fundamentals](https://developers.google.com/web/fundamentals/performance)
  - **Security (2-4 weeks)**
    - Resources: [OWASP](https://owasp.org/)
  - **Responsive Design (2-4 weeks)**
    - Resources: [FreeCodeCamp Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design/)
