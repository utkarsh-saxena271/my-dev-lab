# 🧪 my-dev-lab

A personal development lab.

This repository is a **general-purpose space** where I put things I learn, experiment with, and try while exploring different technologies.

It may include:
- small experiments and proofs of concept
- learning notes and snippets
- random implementations
- unfinished or exploratory ideas
- cross-tech or curiosity-driven work

There’s no fixed structure or guarantee of completeness — this repo evolves as I learn.

## Philosophy
- low friction to experiment
- one place for ongoing learning
- focused repos only when structure is required

Topic-specific or structured learning (e.g. books, deep dives) may live in separate repositories.  
This repo exists to keep everything else **centralized and flexible**.

Learning by building, breaking, and iterating.
